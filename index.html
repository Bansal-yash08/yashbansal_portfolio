NLP Sentiment Analysis

Built sentiment workflows for IMDB movie reviews and YouTube comments using text cleaning, TF-IDF, classical ML, and deep learning.

  • Processed Kaggle's 50,000-review IMDB dataset with regex cleaning, stopword removal, TF-IDF, Logistic Regression, and Multinomial Naive Bayes.
  • Fetched up to 100 YouTube comments, labeled sentiment with TextBlob, and compared Naive Bayes, SVM, and LSTM models.
