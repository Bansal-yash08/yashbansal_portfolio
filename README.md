# yashbansal_portfolio

This is a static portfolio website for data analyst, business analyst, BI analyst, and Python analyst roles.

## Files

- `index.html` - main portfolio page
- `styles.css` - responsive visual design
- `script.js` - project filters and copy-email interaction
- `assets/` - resume files and project image

## How To Open

Open `index.html` in any browser.

## Best Ways To Publish

### Option 1: GitHub Pages

1. Create a GitHub repository named `portfolio` or `yash-bansal-portfolio`.
2. Upload all files from this folder.
3. Go to repository `Settings` > `Pages`.
4. Choose branch `main` and folder `/root`.
5. Open the GitHub Pages URL after it deploys.

Good for: free public portfolio linked from your resume and LinkedIn.

### Option 2: Netlify

1. Go to `https://app.netlify.com/drop`.
2. Drag this full folder into the page.
3. Netlify creates a public link.

Good for: fastest deployment without Git setup.

### Option 3: Vercel

1. Create a Vercel account.
2. Import the GitHub repository containing this folder.
3. Deploy as a static site.

Good for: clean professional deployment and future upgrades.
